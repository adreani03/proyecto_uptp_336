estructura nueva :b

📁 1. Categorías (Para ordenar el desorden)¿Para qué sirve? Es la etiqueta general 
para agrupar las cosas del laboratorio y que no esté todo mezclado.  Ejemplo 
de qué guarda: "Equipos" (Microscopios), "Reactivos" (Químicos), "Vidriería"
(Tubos de ensayo).  

📖 2. Materias (Las asignaturas de Veterinaria)¿Para qué sirve? Para saber 
qué clases se dictan en el salón y poder amarrar los materiales a una materia
específica.  Ejemplo de qué guarda: "Microbiología II", "Parasitología",
"Enfermedades Infecciosas".  

👤 3. Usuarios (Quiénes interactúan)¿Para qué sirve? El registro oficial 
de todas las personas que van a tocar el sistema. Ningún préstamo se 
genera si la persona no vive aquí.  Ejemplo de qué guarda: La cédula, 
el nombre, el PNF (Veterinaria) y su rol (si es el Administrador
/encargado, un Docente, o un Estudiante). 

🔬 4. Inventario (Los productos y equipos del laboratorio)¿Para qué sirve? 
Es el corazón del almacén. Aquí guardamos tanto los objetos fijos 
(microscopios) como los consumibles (geles,láminas) que nos digas que 
debemos simular para mantener las apariencias.  Ejemplo de qué guarda: 
El nombre del objeto, el tipo (si se presta o se gasta), el número de lote, 
la fecha devencimiento (para los químicos), cuánto hay en stock (mínimo y
máximo), en qué parte del salón está guardado, la hoja de seguridad y
su estado operativo (Disponible, Dañado o Contaminado). 

📝 5. Préstamos (El control de salidas)¿Para qué sirve? La bitácora 
obligatoria cada vez que un profesor pide algo para una clase. Aquí aplicamos
la lógica de saber quién se lo llevó, para qué sección y cómo lo devolvió.
Ejemplo de qué guarda: La cédula del profesor, qué equipo se llevó, para 
qué materia y sección, la hora de salida, la hora de entrega, si se devolvió
roto (dañado) y si el profesor cumplió con el protocolo de limpieza y bioseguridad. 

🔍 6. Movimiento de Inventario (La bitácora de auditoría)¿Para qué sirve? 
Registra los cambios bruscos en los estantes que no son un préstamo. 
Si algo se pierde, se vence o llega mercancía nueva, se anota aquí para 
que el stock cuadre perfectamente.  Ejemplo de qué guarda: Qué producto 
cambió, cuántas unidades (entraron o salieron), la fecha, qué tipo de 
movimiento fue (Extravío,Consumo directo, Entrada nueva) y el motivo 
(ej: "Se rompió un tubo en la práctica del martes")

-- TABLA 1: Categorías
        CREATE TABLE IF NOT EXISTS categorias (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nombre TEXT NOT NULL UNIQUE
        );

        -- TABLA 2: Materias
        CREATE TABLE IF NOT EXISTS materias (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nombre TEXT NOT NULL UNIQUE
        );

        -- TABLA 3: Usuarios
        CREATE TABLE IF NOT EXISTS usuarios (
            cedula TEXT PRIMARY KEY,
            nombre TEXT NOT NULL,
            pnf TEXT,
            rol TEXT NOT NULL CHECK(rol IN ('administrador', 'docente', 'estudiante', 'investigador'))
        );

        -- TABLA 4: Inventario (Equipos y Consumibles juntos)
        CREATE TABLE IF NOT EXISTS inventario (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nombre TEXT NOT NULL,
            categoria_id INTEGER,
            tipo TEXT NOT NULL CHECK(tipo IN ('Equipo', 'Consumible')),
            serial_codigo TEXT UNIQUE,
            numero_lote TEXT,
            fecha_vencimiento TEXT,
            stock_actual INTEGER DEFAULT 0,
            stock_minimo INTEGER DEFAULT 0,
            stock_maximo INTEGER DEFAULT 0,
            estado TEXT DEFAULT 'Disponible' CHECK(estado IN ('Disponible', 'Operativo con Observaciones', 'En Mantenimiento', 'Fuera de Servicio', 'Contaminado')),
            ubicacion TEXT,
            hoja_seguridad TEXT,
            FOREIGN KEY (categoria_id) REFERENCES categorias(id)
        );

        -- TABLA 5: Préstamos
        CREATE TABLE IF NOT EXISTS prestamos (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            docente_cedula TEXT NOT NULL,
            inventario_id INTEGER NOT NULL,
            materia_id INTEGER NOT NULL,
            seccion TEXT NOT NULL,
            fecha_prestamo TEXT DEFAULT CURRENT_TIMESTAMP,
            fecha_devolucion TEXT,
            estado_entrega TEXT NOT NULL,
            estado_devolucion TEXT,
            observaciones TEXT,
            protocolo_limpieza INTEGER DEFAULT 0 CHECK(protocolo_limpieza IN (0, 1)),
            FOREIGN KEY (docente_cedula) REFERENCES usuarios(cedula),
            FOREIGN KEY (inventario_id) REFERENCES inventario(id),
            FOREIGN KEY (materia_id) REFERENCES materias(id)
        );

        -- TABLA 6: Movimiento de Inventario (Auditoría de Stock)
        CREATE TABLE IF NOT EXISTS movimiento_inventario (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            inventario_id INTEGER NOT NULL,
            usuario_cedula TEXT NOT NULL,
            tipo_movimiento TEXT NOT NULL CHECK(tipo_movimiento IN ('Entrada', 'Consumo Directo', 'Extravío', 'Mal Estado')),
            cantidad INTEGER NOT NULL,
            fecha TEXT DEFAULT CURRENT_TIMESTAMP,
            motivo TEXT,
            FOREIGN KEY (inventario_id) REFERENCES inventario(id),
            FOREIGN KEY (usuario_cedula) REFERENCES usuarios(cedula)
        );
    ";

OK por mi parte para crear la base de datos tanto archivo como carpetas fue y lo que vos tenes que hacer es:

1) Descargate el Sqlite: https://sqlite.org/2026/sqlite-src-3530200.zip
lo descomrpimes borras el archivo comprimido y ya literal

2) Creas una carpeta en tu computadora llamada control_microbiologia.

3) la carpeta control_microbiologia la tienes que meter obligatoriamente
dentro de la carpeta htdocs de XAMPP.

4) Dentro de esa carpeta, creas un único archivo de bloc de notas, o en
visual studio code si lo tienes baybyy pegas el código que esta arriba lo 
guardas con el nombre init_db.php. y el init_test_db.php para la prueba

5) Abres el panel de XAMPP y le das Start únicamente a Apache (el botón de 
MySQL lo puedes dejar apagado si quieres, ya que no lo vamos a usar).

6) Abres tu navegador favorito (Chrome, Edge, Firefox).

7) En la barra de direcciones escribes: localhost/control_microbiologia/init_test_db.php
(para crear el de pruebas) Y/o

localhost/control_microbiologia/init_db.php (para el limpio). ¡Y ya!

     a) PHP verá que no existe el archivo de la base de datos y creará el archivo
     físico microbiologia.db en tu carpeta.
     b)Inyectará las 6 tablas vacías y los datos de prueba automáticamente dentro 
     de ese archivo. (si usaste el de test )

8) Para ver las tablas Recomendación: Para que puedan ver las tablas de forma visual con clics (como en phpMyAdmin),
instálense en su Visual Studio Code la extensión llamada 'SQLite Viewer'. Les permitirá abrir el archivo .db
y revisar todo cómodamente
